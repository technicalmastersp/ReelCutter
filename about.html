About the project

Built for creators who publish a lot.

Reel Cutter exists because turning one long video into a week of Reels shouldn't mean uploading your footage to a stranger's server and waiting in a queue.

A splitter, not an editor

Reel Cutter takes a single long MP4 or MOV file and divides it into a series of shorter parts — 150–160 seconds each by default, though you can set any range you like. Each part is labeled by filename (Part 1, Part 2, and so on) so you can drop them straight into a posting schedule.

It does one job well: cutting a long recording — a podcast, a livestream, a class, a long-form YouTube video — into pieces sized for short-form platforms. It doesn't add captions, transitions, or effects; there are plenty of good tools for that already.

No upload, by design

Rather than sending your file to a server, Reel Cutter reads the video's container format directly in JavaScript, using a hand-written MP4 box parser. It locates the existing keyframes and copies the compressed audio/video samples straight into new files, then packs them into a zip using a hand-written zip writer — also running locally.

Nothing is re-encoded, so there's no quality loss and no server-side processing queue. The trade-off is that very long or extremely high-resolution files can use a lot of browser memory, especially on phones — see the tips on our tutorials page if you run into that.

Creators repurposing long-form content

Podcasters clipping an episode into daily Reels, educators splitting a lecture into a course-style series, streamers turning a VOD into highlights — anyone who records long and needs to post short.

Free, ad-supported

Reel Cutter has no account, no watermark, and no per-file limit. The site is supported by the ads you see on this page rather than by subscriptions or fees.
