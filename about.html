About the project

Built for creators who publish a lot.

Reel Cutter exists because turning one long video into a week of Reels shouldn't mean uploading your footage to a stranger's server and waiting in a queue.

A splitter, not an editor

Reel Cutter takes a single long MP4 or MOV file and divides it into a series of shorter parts — 150–160 seconds each by default, though you can set any range you like. Each part is labeled by filename (Part 1, Part 2, and so on) so you can drop them straight into a posting schedule.

It does one job well: cutting a long recording — a podcast, a livestream, a class, a long-form YouTube video — into pieces sized for short-form platforms. It doesn't add captions, transitions, or effects; there are plenty of good tools for that already. Keeping the tool single-purpose is deliberate — it means the one thing it does, it does fast and without any quality loss.

No upload, by design

Rather than sending your file to a server, Reel Cutter reads the video's container format directly in JavaScript, using a hand-written MP4 box parser. It locates the existing keyframes and copies the compressed audio/video samples straight into new files, then packs them into a zip using a hand-written zip writer — also running locally.

Nothing is re-encoded, so there's no quality loss and no server-side processing queue. The trade-off is that very long or extremely high-resolution files can use a lot of browser memory, especially on phones — see our troubleshooting guide if you run into that.

The technical short version

MP4 and MOV files store video as a series of compressed samples, indexed by a table that records where each sample sits in the file and which ones are full "keyframes" that don't depend on any other frame. Reel Cutter's parser reads that index (or, for fragmented MP4s, reconstructs the equivalent from the file's moof/trun boxes), figures out which keyframe is closest to your requested split point, and copies the raw bytes from that point onward into a new file with its own valid index. No pixel is ever decoded or re-compressed — the bytes for a given frame in your output file are identical to the bytes for that frame in your source file.

That's also why a split can't land at an arbitrary exact second — it can only start at an existing keyframe. Our keyframes explainer covers this in more depth, and the format glossary defines the underlying terms if you want the full picture.

Creators repurposing long-form content

Podcasters clipping an episode into daily Reels, educators splitting a lecture into a course-style series, streamers turning a VOD into highlights, and anyone digitizing old home movies into browsable chunks — anyone who records long and needs shorter, organized files. See who uses Reel Cutter for detailed workflows per use case.

What Reel Cutter doesn't do

Because splitting is a byte-copy operation rather than an edit, there are things it intentionally can't do: it can't cut at an arbitrary exact frame (only at existing keyframes), it can't change resolution or codec, and it can't remove a section from the middle of a file — it only splits sequentially. If you need any of that, a full editor is the right tool for that step; Reel Cutter is meant to handle the "make it shorter, keep it lossless, do it fast" part of the workflow.

Free, ad-supported

Reel Cutter has no account, no watermark, and no per-file limit. The tool is free to use and is intended to be supported by advertising rather than by subscriptions or fees. Advertising never changes how the tool works, and ads are kept away from the split and download controls so they cannot be clicked by accident.

How the guides on this site are written

The tutorials, glossary and troubleshooting pages exist to explain what the tool actually does — the file formats it handles, the errors it reports and the limits of byte-copy splitting. They are written for readers of this site rather than aggregated from other sites, and they are revised when the tool's behaviour changes or when a reader reports something unclear. Platform figures such as maximum clip lengths change often, so those pages say so and point you to each platform's own help pages for the current numbers.

If you find an error, an outdated figure or a step that did not work for your footage, please tell us through the contact page. Corrections are made on the page itself, and the page's last-updated date changes when they are.

Roadmap

Planned improvements include broader container format support, clearer in-tool guidance when a file can't be parsed, and expanded documentation based on the errors and formats people actually run into. Feedback from real usage — via the contact page — directly shapes what gets prioritized next.

Frequently asked questions

Is Reel Cutter affiliated with Instagram, TikTok, or YouTube?
No. Reel Cutter is an independent tool. "Reels," "TikTok," and "Shorts" are used here only to describe the short-form video formats these platforms popularized, not to imply any partnership or endorsement.
Who built Reel Cutter?
Reel Cutter is built and maintained independently, motivated by a simple frustration: existing "video splitter" tools online either required an upload (slow, and a privacy concern for unpublished footage) or a full desktop editor (overkill for a task that's really just "cut this file into pieces"). The MP4 parsing and zip packing were written from scratch specifically to avoid pulling in a heavy library just to do a straightforward byte-copy.
Will Reel Cutter always be free?
That's the plan. The site is supported by advertising rather than a paid tier, which keeps the core tool free to use without an account or usage limits.
