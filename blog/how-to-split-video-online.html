How to split a video online, step by step

A complete walkthrough of splitting one long video into timed parts in your browser: what to click, what the tool is doing, and how to check the result.

Last updated: 3 October 2026

Splitting a long video into shorter parts used to mean opening a timeline editor, placing markers by hand, and waiting for an export. With Reel Cutter you can do it in a browser tab in a few clicks, and the file never leaves your device. This guide walks through every step in the order you will see it on screen, explains what the tool is doing at each stage, and shows you how to check that the result is what you wanted.

By the end you will have a single video_parts.zip containing one MP4 per part, each starting cleanly and each as sharp as your original, because nothing is re-encoded.

Before you start

  • A video file in MP4, MOV or M4V. Phone recordings, screen recordings and most editor exports already are. MKV, AVI and WebM files are not supported; convert them to MP4 first (see the troubleshooting guide).
  • Free storage roughly equal to the file size. Parts are copies of the original data and the zip stores them without compression, so video_parts.zip ends up about the same size as the source.
  • A current browser. Chrome, Edge, Firefox and Safari all work. For files in the multi-gigabyte range, use a laptop or desktop rather than a phone (see splitting video on a phone).
  • Footage you own or have permission to use. The tool does not check, so that responsibility is yours.

Step 1: Open the tool and choose your video

Go to the split tool on the home page. Tap or click the large drop zone labelled “Tap to choose a video”, or drag a file onto it on a computer. On a phone this opens the system picker for photos and videos or files.

Once a file is chosen you will see its name and size under the drop zone, a small preview player appears, and the main button changes from “Choose a video first” to “Split this video (fast, lossless)”. The preview is only there so you can confirm you picked the right file; it plays straight from your device.

Step 2: Decide how long each part should be

The “Cut settings” card has a minimum and a maximum length in seconds. They default to 150 and 160. The tool does not cut a part the instant it reaches the minimum; instead it plans the whole job up front, like this:

  1. It takes the midpoint of your two numbers as the target length (155 seconds with the defaults).
  2. It divides the total duration by that target and rounds up to get the number of parts.
  3. It divides the duration by that number of parts to get one even length for every part.
  4. If that even length would fall below your minimum, it switches to your maximum as the part length instead, which usually leaves a shorter final part.

Here is what that produces for a few real inputs. These figures come straight from the tool's planning rules, so you can use them to predict your own result before you run anything (or use the split planner, which applies the same rules).

The 1,300-second row is worth studying: an even split into nine parts would give about 144 seconds each, which is under the 150-second minimum, so the tool uses 160 seconds per part instead. If you do not want a short tail, nudge the minimum or maximum until the numbers divide more evenly, or accept that the last part is simply what is left over.

Step 3: Set a label and decide about audio

Part label prefix. The default is “Part”. It is used in the progress list (“Part 1”, “Part 2”…) and in each filename. Letters and numbers are kept; any other characters become hyphens. With the default, your first file is named part_1_Part-1.mp4. If you type “Episode”, you get part_1_Episode-1.mp4.

Include audio. “Yes” keeps the audio. “No (video only)” leaves it out of every part. If your file has more than one audio track, only the first is copied. Other tracks, such as alternate languages or subtitle tracks, are not included.

Step 4: Run the split

Press “Split this video (fast, lossless)”. You will see these stages:

  • Reading file structure. The tool reads the index of your MP4 (the part of the file that describes every frame and where it lives) and finds the keyframes. The log box below the button prints the detected duration and how many parts are planned.
  • Building parts. A checklist shows each part moving from “preparing…” to “done” with its size in megabytes. The tool copies the original compressed audio and video data for that range into a new MP4 and writes a fresh index for it.
  • Packing zip. All finished parts are bundled into one archive in memory.

An elapsed timer and an estimated time remaining sit above the progress bar. Because nothing is decoded or re-encoded, the work is mostly reading and copying bytes, so it is bounded by how fast your device can read the file and how much memory the browser lets the tab use rather than by video complexity. Keep the tab open and in the foreground until it finishes; if you close or reload it, the work in memory is lost and you start again.

Step 5: Download and unzip

When the progress bar reaches 100% a “Download zip” button appears. It saves video_parts.zip using your browser's normal download flow. Unzip it with your operating system's built-in tool and you will find one MP4 per part, numbered in order. Nothing has been saved anywhere until you press that button.

Step 6: Check the result

Spend a minute on quality control before you publish anything:

  1. Play the first few seconds of every part. Each should start cleanly with a full picture and no gray or smeared frames.
  2. Compare the lengths. Parts are allowed to differ from your target by a few seconds because cuts land on keyframes (explained in MP4 keyframes, explained simply). The last part is often shorter.
  3. Listen across a boundary. Play the end of one part and the start of the next. Each part begins where the previous one ended, so you should hear continuous speech or music, although a cut can land mid-sentence because it snaps to the picture, not the dialogue.
  4. Check the file sizes add up. The parts should total roughly the size of your original.

What this tool will not do

Reel Cutter divides a whole video into consecutive parts. It does not let you choose a custom start and end to keep one clip, remove a section from the middle, crop to vertical, add captions, or convert formats, and it cannot cut on an exact frame. If that is what you need, read video cutter vs. video splitter for the right order of steps, which often means trimming in an editor first and splitting second.

If something goes wrong

Most problems fall into three groups: a file in an unsupported container (convert to MP4), a very large file that exhausts the browser's memory (use a desktop browser, or split a smaller file), or a source with unusually sparse keyframes (parts drift further from your target). The troubleshooting guide covers each error message, and the FAQ answers the common questions in one place.
