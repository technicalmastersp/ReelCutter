Split a video on your phone

Why phone browsers behave differently from laptops, how to avoid the most common crash, and what to do with the zip afterwards.

Last updated: 3 October 2026

Reel Cutter works in a phone browser, and for many people that is the whole point: record on the phone, split on the phone, post from the phone. But a phone browser has far less memory to work with than a laptop, so a little planning prevents the most common failure, a tab that crashes partway through. This guide explains why that happens, based on how the tool actually processes a file, and how to avoid it.

What the tool does with your file's memory

Reading the file is cheap: the tool only reads the small index at the start or end of the MP4 and then pulls out the chunks it needs. Building the output is where memory goes up:

  1. Each part is assembled and held in memory as a finished MP4.
  2. When every part is ready, all of them are copied into a single zip, which is also assembled in memory.
  3. Only then is the download offered.

Our reading of this process is that, near the end, the browser can be holding the finished parts and the packed zip at the same time, so peak memory use can reach roughly two to three times the size of the source file. That is an estimate from how the steps are written, not a benchmark, and the real number varies by browser and device. It explains why a file that is comfortable on a laptop with plenty of RAM can crash a phone tab.

Practical guidelines

  • Test with a short clip first. Run a one- or two-minute clip through the tool to learn how your phone behaves before you try an hour-long recording.
  • Treat large files with caution. We have no hard limit in the tool, because limits depend on your device. As a conservative starting point, files of a few hundred megabytes are far more likely to succeed on a phone than files of several gigabytes. If a big file fails, move it to a computer.
  • Close other tabs and apps before you start. They compete for the same memory pool.
  • Stay on the tab. Mobile browsers can pause or discard background tabs to save memory. If you switch away mid-split and the tab reloads, nothing is saved and you must start over.
  • Plug in if the file is long. It is a sustained job for the processor.
  • Check free storage. The zip needs about as much space as the original video.

Choosing the file

Tap the drop zone and your phone opens its own picker, so you can select from your camera roll or from files. The tool accepts MP4, MOV and M4V. Many phones record video as MP4 or MOV by default, often with the HEVC (H.265) codec on newer devices. Because Reel Cutter copies the compressed data without changing it, each part keeps the same codec as the original and plays wherever the original plays. It also keeps the original track header, which is where rotation information lives, so portrait recordings stay portrait.

After the split

When you press “Download zip”, the phone's browser saves video_parts.zip to its normal downloads location. To use the parts you need to extract the zip. Most current phones can open zip files from their built-in file manager; if yours cannot, a free file-manager app can. Once extracted, the parts are ordinary MP4 files you can share or upload from your phone.

If the tab crashes

  1. Reload the page. Nothing is stored between sessions, so you start from the beginning.
  2. Close everything else and try again on a shorter version of the file.
  3. Or use a laptop. A desktop browser usually has far more memory available to a single tab.

The troubleshooting guide lists other messages you may see, including the one shown when a file uses an unsupported variant of the MP4 format.

Is it safe to use on mobile data?

Splitting does not upload or download your video, so it uses essentially no mobile data once the page itself has loaded. The only data you spend is on loading the website. You can read why in Is my video uploaded? How to verify it yourself.
