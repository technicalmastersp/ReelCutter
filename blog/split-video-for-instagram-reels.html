Splitting a long video into Instagram Reels

Turn one long recording — a podcast, a class, a livestream — into a batch of ready-to-post Reels, without uploading the file anywhere.

If you've got a 20-minute recording and want to post it as a series of Reels, you have two basic options: re-encode it in a heavy desktop editor, or copy the existing compressed video straight into shorter files. This guide covers the second approach using Reel Cutter, which does the whole job in your browser tab.

Before you start

  • Export or save your source video as a standard MP4 or MOV file if it isn't already.
  • Decide roughly how long you want each part — 150–160 seconds works well for a lot of Reels workflows, but there's no single right answer (see our clip length guide).
  • On a phone, make sure you have a bit of free storage — the finished zip needs to be written to disk before you can share it.

Step 1: Choose your video

Open the split tool and tap the drop zone, or drag a file in on desktop. The tool reads the file directly from your device — it doesn't upload it anywhere, so there's no waiting on a connection before processing starts.

Step 2: Set your cut settings

Enter a minimum and maximum length in seconds. The tool will aim to land each part somewhere in that range, snapping to the nearest existing keyframe so playback starts cleanly. You can also:

  • Set a label prefix, so parts are named "Part 1," "Episode 1," or whatever fits your series.
  • Choose whether to keep the audio track — useful if you want a video-only cut for a specific edit later.

Step 3: Run the split

Click "Split this video" and watch the checklist update as each part is built. Because there's no re-encoding involved, this is typically much faster than exporting the same number of clips from a timeline editor — the tool is copying existing compressed data, not recompressing it.

Step 4: Download and post

Once every part is built, download the zip. Inside you'll find one MP4 per part, ready to upload to Instagram, TikTok, or YouTube in whatever order you like. Because nothing was re-encoded, each part looks exactly as sharp as your original file.

Troubleshooting

A part is a few seconds longer or shorter than I asked for
This is expected — see why cuts snap to keyframes. Narrowing the gap between min and max length usually tightens this up.
The tool says the file failed to parse
This usually means the file uses a fragmented or unusual MP4 structure. Re-exporting it as a standard MP4 from your camera app or editor first almost always fixes it.
My phone's browser tab crashed partway through
Very long or very high-resolution source files can use a lot of memory. Try a shorter source clip, lower the source resolution first, or run the split on a laptop instead.
