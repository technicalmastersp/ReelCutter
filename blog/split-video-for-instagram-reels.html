Splitting a long video into Instagram Reels

Turn one long recording — a podcast, a class, a livestream — into a batch of ready-to-post Reels, without uploading the file anywhere.

If you've got a 20-minute recording and want to post it as a series of Reels, you have two basic options: re-encode it in a heavy desktop editor, or copy the existing compressed video straight into shorter files. This guide covers the second approach using Reel Cutter, which does the whole job in your browser tab — no install, no upload, no export queue.

Why byte-copy splitting beats re-encoding for this job

Traditional editors cut video by decoding every frame back into raw pixels, then recompressing the pieces you keep. That's necessary when you're trimming mid-scene or changing resolution, but it's overkill for a straight split — and it costs you two things: time (a 20-minute 1080p file can take several minutes to re-export) and quality (recompressing an already-compressed video at a lower bitrate than the original introduces generational loss, the same way re-saving a JPEG repeatedly degrades it). A byte-copy split skips all of that: it reads where each compressed frame already sits in the file and copies those bytes directly into new files. The output is bit-for-bit identical to the source, and building even a dozen parts typically takes a few seconds rather than minutes.

Before you start

  • Export or save your source video as a standard MP4 or MOV file if it isn't already. Reel Cutter also supports fragmented ("streaming-style") MP4s, so exports from most phone cameras, screen recorders, and editors will work as-is.
  • Decide roughly how long you want each part — 150–160 seconds works well for a lot of Reels workflows, but there's no single right answer (see our clip length guide).
  • On a phone, make sure you have a bit of free storage — the finished zip needs to be written to disk before you can share it.
  • If your recording has a long musical intro, dead air, or a section you don't want in any part, trim that out in your camera app or editor first — Reel Cutter splits sequentially, it doesn't remove sections from the middle.

Step 1: Choose your video

Open the split tool and tap the drop zone, or drag a file in on desktop. The tool reads the file directly from your device — it doesn't upload it anywhere, so there's no waiting on a connection before processing starts, and no file-size limit imposed by a server-side upload cap.

Step 2: Set your cut settings

Enter a minimum and maximum length in seconds. The tool will aim to land each part somewhere in that range, snapping to the nearest existing keyframe so playback starts cleanly. You can also:

  • Set a label prefix, so parts are named "Part 1," "Episode 1," or whatever fits your series and matches your posting calendar naming convention.
  • Choose whether to keep the audio track — useful if you want a video-only cut for a specific edit later, or if you're planning to add a separate voiceover per part.

Step 3: Run the split

Click "Split this video" and watch the checklist update as each part is built. Because there's no re-encoding involved, this is typically much faster than exporting the same number of clips from a timeline editor — the tool is copying existing compressed data, not recompressing it. A 30-minute source file usually finishes in well under a minute on a modern phone or laptop.

Step 4: Download and post

Once every part is built, download the zip. Inside you'll find one MP4 per part, ready to upload to Instagram, TikTok, or YouTube in whatever order you like. Because nothing was re-encoded, each part looks exactly as sharp as your original file — there's no visible seam between "part 3" and what part 3 would have looked like if you'd exported it directly from a timeline editor.

A simple posting workflow

Once you have your zip of parts, a few habits make the multi-part posting process smoother:

  • Rename before you upload. If your platform's app doesn't show upload order clearly, prefix filenames with numbers (01_, 02_...) so you post them in sequence.
  • Add a "part X of Y" caption or on-screen label in your platform's own caption/text tool so viewers who land on part 3 first know to look for part 1.
  • Space posts out rather than uploading all parts back-to-back — most platforms favor content spaced over hours or days for a single source recording, rather than a flood of posts in one sitting.
  • Pin the first part or link it in later parts' captions/comments so newcomers can find the start of the series.

Troubleshooting

A part is a few seconds longer or shorter than I asked for
This is expected — see why cuts snap to keyframes. Narrowing the gap between min and max length usually tightens this up.
The tool says the file failed to parse
This usually means the file uses an unsupported or corrupted container variant. Re-exporting it as a standard MP4 from your camera app or editor first almost always fixes it. See our full troubleshooting guide for source-specific tips.
My phone's browser tab crashed partway through
Very long or very high-resolution source files can use a lot of memory. Try a shorter source clip, lower the source resolution first, or run the split on a laptop instead.
Can I split a video that already has captions or text overlays burned in?
Yes — burned-in captions, watermarks, or overlays are part of the video's pixels, so they carry through into every part exactly as they appear in the source. Reel Cutter doesn't add, remove, or alter any visual elements.
Do I need to convert my file before splitting it?
Not usually. Standard and fragmented MP4/MOV/M4V files both work directly. If your file is a different container (like AVI, MKV, or WebM), convert it to MP4 in your editor or camera app's export settings first.
